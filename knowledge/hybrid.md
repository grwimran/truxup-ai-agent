# Truxup — Hybrid Logistics

## Overview

Truxup supports companies that operate both carrier and broker workflows.

A hybrid logistics company may perform both carrier-side and broker-side transportation activities. Truxup provides an integrated workspace for these workflows.

## Integrated Workspace

Truxup supports an integrated environment for managing carrier and broker operations.

This allows hybrid companies to work with both sides of their transportation business within Truxup.

## Hybrid Capabilities

Confirmed hybrid capabilities include:

* Load matching
* Shared visibility
* Scheduling
* Dispatch
* Communication
* Tracking
* Reporting and analytics

## Load Matching

Truxup supports load matching as part of hybrid transportation workflows.

This can help businesses manage transportation activity involving both carrier and broker operations.

## Shared Visibility

Truxup provides shared visibility across transportation workflows.

Users can maintain visibility into loads and transportation activity.

## Scheduling

Truxup supports scheduling and dispatch workflows.

The Dynamic Scheduler provides capabilities including:

* Load assignments
* Unassigned driver visibility
* HOS-related considerations
* Scheduling
* Drag-and-drop workflow

## Dispatch

Truxup supports dispatch workflows for transportation operations.

Hybrid businesses can use dispatch capabilities as part of their carrier-side operations.

## Communication

Truxup supports communication within transportation workflows.

This helps teams coordinate activities between relevant users.

## Tracking

Truxup provides real-time tracking and updates.

The platform also provides Live Map visibility.

## Reporting and Analytics

Truxup provides reporting and analytics capabilities to help transportation businesses review their operations.

## Hybrid Use Case

A hybrid logistics company can manage both carrier and broker workflows through an integrated Truxup environment.

For example:

Carrier Operations + Broker Operations → Integrated Truxup Workspace
