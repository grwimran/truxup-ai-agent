# TruxUp Security FAQ

## Security Information

The AI assistant must only provide security information explicitly
approved in the TruxUp knowledge base.

## Unknown Security Questions

If a prospect asks about a specific security certification, compliance
standard, encryption method, hosting architecture, penetration testing
process, or security control that is not documented:

"I don't have confirmed information about that security requirement in my
current product information. I can note it as a requirement for the
TruxUp team to address during the evaluation."

## Do Not Invent

Never claim:

- SOC 2 certification
- ISO certification
- HIPAA compliance
- PCI compliance
- Specific encryption standards
- Specific cloud providers
- Specific data-center locations
- Specific backup policies

unless explicitly documented.

## Security Discovery

When security is important, ask:

"What security or compliance requirements does your organization need the
TMS to meet?"

This allows the sales process to identify requirements without making
unsupported claims.
